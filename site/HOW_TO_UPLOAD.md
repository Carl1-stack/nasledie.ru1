# Upload the B1 lessons to GitHub (separate from A1)

The B1 pages live in their own folder **b1/** in the repo Carl1-stack/nasledie.ru1, apart from A1's quiz_site/.
Link for B1 students (one link for all B1 lessons): https://carl1-stack.github.io/nasledie.ru1/b1/

## First time (create the b1 folder)
1. Open https://github.com/Carl1-stack/nasledie.ru1 (the main page of the repo, NOT inside quiz_site).
2. Add file → Upload files.
3. Open `D:\Russian Home\Russian Club\B1_Course\site\` in Windows Explorer and drag the whole **b1** folder onto the GitHub page.
   GitHub keeps the folder, so the files land in b1/index.html and b1/lesson01.html.
4. Commit changes (green button at the bottom).
5. Wait 1–2 minutes, then open https://carl1-stack.github.io/nasledie.ru1/b1/

## Every new lesson
1. Open https://github.com/Carl1-stack/nasledie.ru1/tree/main/b1 (the b1 folder).
2. Add file → Upload files.
3. Drag from `B1_Course\site\b1\` the new **lessonNN.html** and **index.html** (index.html adds the new lesson to the list).
4. Commit changes. Wait 1–2 minutes and refresh the link.
